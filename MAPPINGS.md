# Mappings

**Trigger** = hold `CapsLock`. It replaces the PowerToys `Ctrl+Alt+Shift` combo. Tapping `CapsLock` sends `Esc`.

| Shortcut | Action |
| --- | --- |
| Trigger + `H` `J` `K` `L` | ← ↓ ↑ → |
| Trigger + `W` / `S` | ↑ / ↓ |
| Trigger + `A` or `[` | Previous tab |
| Trigger + `D` or `]` | Next tab |
| Trigger + `I` | Backspace |
| Trigger + `O` | Delete word |
| Trigger + `N` | Esc |
| Trigger + `Q` | Close window (Alt+F4) |
| Trigger + `Space` | Enter |

## Other remaps

| Key | Becomes |
| --- | --- |
| Left `Alt` | Left `Ctrl` |
| Left `Ctrl` | Left `Alt` |
| Right `Alt` | `Ctrl` |

Emergency exit: Left `Ctrl` + `Space` + `Esc`.
