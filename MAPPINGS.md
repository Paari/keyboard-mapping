# Mappings

**Trigger** = hold `CapsLock`. Tapping `CapsLock` sends `Esc`.

## Actions (both systems)

| Shortcut | Action |
| --- | --- |
| Trigger + `H` `J` `K` `L` | ← ↓ ↑ → |
| Trigger + `W` / `S` | ↑ / ↓ |
| Trigger + `A` or `[` | Previous tab |
| Trigger + `D` or `]` | Next tab |
| Trigger + `I` | Backspace |
| Trigger + `O` | Delete word (Linux: Ctrl+Backspace; macOS: Option+Backspace) |
| Trigger + `N` | Esc |
| Trigger + `Q` | Close window (Linux: Alt+F4; macOS: Command+W) |
| Trigger + `Space` | Enter/Return |

## Linux modifier remaps

| Key | Becomes |
| --- | --- |
| Left `Alt` | Left `Ctrl` |
| Left `Ctrl` | Left `Alt` |
| Right `Alt` | `Ctrl` |

## macOS modifier remaps

None. `Ctrl`, `Option` (Alt), and `Command` keep their normal macOS behavior.

Emergency exit: Left `Ctrl` + `Space` + `Esc`.
